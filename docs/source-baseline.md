## 保留

保留批量生成邮箱、收发邮件、验证码提取、用户/邮箱管理、权限校验、HTML 清洗、限流、过期清理和现有界面。

本次没有部署 Cloudflare，也没有新增或运行测试。后续大改可以直接基于本目录进行；需要 Git 时再初始化新仓库。
