# Veil 优化发布说明

## P0 到 P7 汇总

P0 处理基础正确性和内容解析问题，统一验证码提取、邮件预览和详情渲染。

P1 优化数据库 Schema 和 D1 查询路径，补齐初始化 SQL、索引和迁移脚本。

P2 拆分后端模块，路由、鉴权、数据库、邮件、发件、清理和资源访问职责分离。

P3 拆分前端 ES Modules，保留无构建 Vanilla JS 架构，同时限制文件和函数体积。

P4 补齐自动化测试深度，覆盖 API/RBAC、收信、发信、TTL 清理和前端交互。

P5 加固安全边界，Root 覆盖令牌显式化，敏感入口默认限流，收信注入增加大小校验。

P6 增加部署可观测性和健康检查，启用 Wrangler 日志，新增运行手册和配置状态输出。

P7 完成产品收尾，入口加载页支持安全重定向和失败重试，README、API 文档、一键部署说明与发布说明同步。

## 验证方式

发布前执行完整语法和测试验证。

```bash
node --check
node --test
```

本仓库的实际验证命令会递归检查 `src`、`public`、`tests` 下的 JavaScript 文件，并运行 `tests` 目录内的全部 Node 测试。
