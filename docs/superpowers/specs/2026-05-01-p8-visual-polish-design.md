# P8 Visual Polish Design

P8 只处理视觉质感，不改 API、权限、路由、存储和业务状态。上一轮 UI 优化已经把样式结构拆开，P8 继续复用这个结构，把好看这件事落在稳定的 CSS 入口和少量现有渲染类上。

现有界面的问题不是功能缺失，而是视觉重心偏平。首页邮箱地址没有足够的主视觉，卡片和列表层次接近，空状态像占位文字，暗色模式缺少品牌光感。解决方案是新增 `visual-polish.css`，放在 `styles.css` 最后加载，只覆盖视觉表现，不改变 DOM 事件、数据读取和权限判断。

视觉方向改为低饱和灰蓝，只作用于进入应用后的 `app-mode` 和 `page-scroll` 页面。登录页保留原来的登录视觉。主邮箱展示区恢复为无大背景框的原始结构，只保留长邮箱地址换行和字号约束，避免内容挡住。应用内不再使用鲜艳渐变或紫色，动效只保留必要 hover，`prefers-reduced-motion` 下关闭非必要动画。

验收标准是样式入口仍稳定，视觉增强集中在独立 partial，每个 CSS 文件不超过 300 行，静态 HTML 不重新引入内联样式，现有前端模块导入不受影响。
